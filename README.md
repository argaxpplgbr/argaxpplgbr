## Publish the website with GitHub Pages

The included GitHub Actions workflow deploys this repository to Pages on each push to `main`. After the first push, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The site will be available at `https://argaxpplgbr.github.io/`.

## Push this package

In **Windows Command Prompt (CMD)**, first change to the folder where you extracted this ZIP, then run:

```cmd
cd /d "%USERPROFILE%\Downloads\argaxpplgbr-profile"
git init
git branch -M main
git add .
git commit -m "Build GitHub profile website"
git remote add origin https://github.com/argaxpplgbr/argaxpplgbr.git
git push -u origin main
```

If `origin` is already configured, use `git remote set-url origin https://github.com/argaxpplgbr/argaxpplgbr.git` instead of `git remote add origin ...`.
